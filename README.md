# Playbook Hub

개인 비공개 지식 허브 + 프로젝트 관제탑.

## 기능
- MDX 기반 위키 (지식 그래프, 검색, 카테고리)
- 학습 트래커 (스트릭, 히트맵, Quiz SRS)
- /projects 프로젝트 관제탑
- Gemini AI 자동 콘텐츠 생성
- 허브-워커 양방향 개선 시스템
- HMAC 쿠키 인증 (비공개)

## 기술 스택
- Next.js 16 (App Router, MDX)
- Tailwind CSS 4, TypeScript
- Vercel + GitHub Actions
