LLM (Large Language Model) API 호출 및 프롬프트 보안은 AI 시스템의 신뢰성을 보장하는 데 필수적인 요소입니다. 특히 민감 정보가 포함된 프롬프트가 LLM 제공업체나 리셀러의 시스템을 통과할 때, 예상치 못한 데이터 유출 리스크가 발생할 수 있습니다. 2026년 Dragos의 조사 결과는 AI 공급망 내에서 프롬프트 탈취, 개인정보 보호 설정 위반, 심지어 테스트 자격 증명 유출과 같은 심각한 보안 문제를 드러냈습니다. 이러한 위협에 대응하기 위한 효과적인 전략 중 하나는 카나리 토큰(Canary Token)의 도입입니다.

## 카나리 토큰이란 무엇인가?

카나리 토큰은 시스템 내에 의도적으로 심어 놓은 추적 가능한 비밀 정보입니다. 이 토큰이 예상치 못한 위치에서 감지되면, 이는 곧 데이터 유출이나 무단 접근 시도가 있었음을 나타내는 경고 신호로 작동합니다. LLM 환경에서는 프롬프트 내에 고유하고 추적 가능한 문자열을 삽입하여, 해당 프롬프트나 그 일부가 유출되었을 때 알림을 받을 수 있도록 설계됩니다.

### LLM 프롬프트 보안에서의 카나리 토큰 활용

LLM API 호출 시 사용되는 프롬프트에 카나리 토큰을 삽입하는 것은 다음과 같은 목표를 가집니다:

1.  **조기 유출 감지**: 프롬프트 데이터가 LLM 공급망(LLM provider, reseller, partner ecosystem) 내에서 무단으로 접근되거나 공유될 경우 즉시 감지합니다.
2.  **책임 소재 추적**: 유출된 토큰의 정보를 통해 어느 경로에서 유출이 발생했는지 추적하여 책임 소재를 명확히 합니다.
3.  **보안 정책 준수 모니터링**: LLM 제공업체가 약속한 데이터 무보관(Zero Data Retention, ZDR) 또는 보안 정책 준수 여부를 간접적으로 검증합니다.

### LLM 공급망 보안 정책 재검토 및 Zero Data Retention (ZDR) 활용

카나리 토큰 도입과 더불어, LLM 제공업체 및 리셀러의 보안 정책을 면밀히 재검토하는 것이 중요합니다. 특히 `데이터 무보관(Zero Data Retention, ZDR)` 설정 여부와 그 실제 적용 수준을 확인해야 합니다. ZDR은 API를 통해 전송된 프롬프트와 생성된 응답 데이터를 보관하지 않겠다는 약속이지만, 실제로는 로깅 시스템이나 백업 스냅샷 등에서 데이터가 임시적으로 유지될 수 있습니다. 카나리 토큰은 이러한 ZDR 정책의 실질적인 준수 여부를 테스트하는 도구로 활용될 수 있습니다.
