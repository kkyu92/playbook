## 핵심 개념

**AICore** 는 Android 14+ 에서 도입된 **system-level AI 모델 런타임 서비스** 다. 앱이 직접 모델 가중치를 다루지 않고 OS 가 통합 관리한다는 사상이다. 핵심 책임 4 가지:

1. **모델 배포·업데이트** — Gemini Nano / Gemma 모델 파일을 OS 단위로 다운로드·업데이트
2. **하드웨어 가속** — NPU / GPU / DSP 차이를 추상화, 디바이스마다 best path 자동 선택
3. **안전 필터** — Google 의 safety classifier 를 시스템 레벨에서 강제
4. **자원 격리** — 모델 메모리·디스크 사용량을 앱 budget 에서 분리

이 설계 덕분에 앱은 수 GB 모델을 자기 APK 에 번들하지 않고도 Gemini Nano 추론을 호출할 수 있다. 모델 한 카피를 모든 앱이 공유하므로 디스크·메모리 효율도 높다.

## 주요 기능

### Private Compute Core 원칙 적용
- **제한된 패키지 바인딩** — 시스템 화이트리스트 외 임의 앱은 AICore 와 직접 통신 불가, 화이트리스트 변경은 OTA 만 가능
- **간접 인터넷 접근** — AICore 는 직접 네트워크 접근 X. 모델 다운로드 포함 모든 외부 통신은 Private Compute Services 경유
- **요청 격리·무저장** — 각 추론 요청은 격리, 입력·출력 모두 저장되지 않음

### 모델 카탈로그 (2026)
- **Gemini Nano 2** — Pixel 8 Pro / 9, Galaxy S24 시리즈 등에서 안정 동작
- **Gemma 3 / 4** — open model, AICore Developer Preview 채널에서 제공
- **Gemini Nano 4** (예정) — Gemma 4 기반, 4x 추론 속도 + 60% 배터리 감소, 140+ 언어, 멀티모달

### 개발자 접근 경로
- **ML Kit GenAI APIs** — high-level wrapper (Summarization, Rewriting 등)
- **Google AI Edge SDK** — Gemini Nano 직접 호출 (Prompt API 등)
- **AICore Developer Preview** — Gemma 신 모델 early testing

## 활용 사례

- **앱 작성자 입장** — 자체 모델 배포 파이프라인 구축 없이 GenAI 기능 출시
- **OEM 입장** — 동일 디바이스의 NPU 자원을 여러 앱이 안전하게 공유
- **OS 입장** — 모델 보안 업데이트를 OTA 한 번으로 모든 앱에 전파
- **개인정보 민감 도메인** (의료/금융) — 데이터가 디바이스에서 빠지지 않는 GenAI 사용 가능
- **저전력 시나리오** — 클라우드 추론 대신 NPU 추론으로 배터리 소모 절감

```kotlin
// AICore 직접 접근은 불가, ML Kit GenAI 또는 AI Edge SDK 경유
val summarizer = Summarizer.getClient(
    SummarizerOptions.builder(context)
        .setInputType(InputType.ARTICLE)
        .setOutputType(OutputType.THREE_BULLETS)
        .build()
)

summarizer.prepareInferenceEngine() // AICore 가 모델 준비
    .addOnSuccessListener {
        summarizer.runInference(text).addOnSuccessListener { result ->
            Log.d("AICore", result.summary)
        }
    }
```

## 한계 및 고려사항

- **디바이스 분포 좁음** — 2026 시점에서도 flagship 위주. 중·저가 디바이스 fallback 전략 필수
- **모델 버전 통제권 없음** — OS 가 모델 버전을 결정. 앱은 특정 모델 버전 lock 불가 → behavior drift 가능
- **간접 접근 only** — 앱이 AICore 와 직접 binder 통신 불가. 항상 SDK 우회 → 디버깅 시 black box
- **안전 필터 false positive** — 시스템 필터가 합법 컨텐츠를 차단할 수 있음. UX 에서 graceful failure 처리 필요
- **콜드 스타트 비용** — 첫 inference 시 모델 로드 시간 발생 → prefetch / warmup API 활용
- **OEM 별 디바이스 인증 차이** — 동일 모델명이라도 AICore 지원 SKU 가 region/carrier 별로 다를 수 있음
- **Cloud fallback 자동 X** — Nano 실패 시 cloud Gemini 호출은 앱이 직접 처리해야 함
