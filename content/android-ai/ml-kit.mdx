## 핵심 개념

**ML Kit** 은 Google 이 제공하는 **무료 모바일 ML SDK** 로, "production-ready 모델을 몇 줄로 호출" 이 목표다. 내부적으로 Vision API 는 TFLite, GenAI API 는 Gemini Nano + AICore 를 호출하지만 앱 개발자는 그 디테일을 알 필요가 없다.

ML Kit 의 위치를 정리하면:
- **MediaPipe** = 그래프 기반 미디어 파이프라인, 크로스플랫폼 (Web/Python 포함)
- **Google AI Edge SDK** = Gemini Nano 직접 호출 (low-level)
- **ML Kit** = 모바일 (Android + iOS) 한정, task-oriented high-level wrapper

Android API level 23+ (Android 6.0) 이 최소 요구. 대부분 기능이 **on-device** 로 실행되어 오프라인·프라이버시 친화적이다.

## 주요 기능

세 카테고리:

### Vision APIs
- Text Recognition v2 (Latin + 중·일·한·Devanagari 등)
- Face Detection / Face Mesh
- Barcode Scanning
- Image Labeling
- Object Detection & Tracking
- Pose Detection
- Selfie Segmentation
- Document Scanner

### Natural Language APIs
- Language Identification
- Translation (on-device)
- Smart Reply
- Entity Extraction

### GenAI APIs (Gemini Nano 기반, beta)
- Summarization
- Proofreading
- Rewriting
- Image Description
- Prompt API (alpha)

GenAI 카테고리는 사실상 Gemini Nano 의 high-level wrapper 이며, 모델 다운로드·업데이트는 AICore 가 알아서 처리한다.

## 활용 사례

- **명함 스캐너** — Text Recognition v2 + Entity Extraction 으로 이름·전화·이메일 자동 인식
- **결제 앱** — Barcode/QR 스캔 으로 인보이스·결제 자동 처리
- **사진 정리 앱** — Image Labeling + Pose Detection 으로 카테고리·인물 분류
- **챗 앱** — Smart Reply + Rewriting 으로 답장 제안 + 톤 변환
- **번역 앱** — On-device Translation 으로 오프라인 번역

```kotlin
// Text Recognition v2 예시
val recognizer = TextRecognition.getClient(TextRecognizerOptions.DEFAULT_OPTIONS)
val image = InputImage.fromBitmap(bitmap, 0)

recognizer.process(image)
    .addOnSuccessListener { visionText ->
        visionText.textBlocks.forEach { block ->
            Log.d("MLKit", block.text)
        }
    }
    .addOnFailureListener { e -> Log.e("MLKit", "fail", e) }
```

## 한계 및 고려사항

- **GenAI 디바이스 제한** — Gemini Nano 기반 기능은 Pixel 8 Pro / Pixel 9 / Galaxy S24 등 NPU 디바이스 한정. fallback UX 설계 필수
- **iOS 와 기능 비대칭** — 일부 GenAI / Vision 기능은 Android 한정
- **Custom 모델 자유도 낮음** — Custom TFLite 모델 사용은 가능하지만, ML Kit 의 "high-level convenience" 영역에서 벗어남
- **모델 사이즈** — bundled vs unbundled (Google Play Services) 선택지 — bundled 시 APK 가 커짐
- **Beta/Alpha 의존성** — GenAI 카테고리는 안정화 진행 중. production rollout 전 release notes 확인 필수
- **Firebase ML 과의 구분** — 과거 Firebase 와 분리되어 standalone SDK 가 된 변천사. 옛 문서 ↔ 신 문서 혼동 주의
