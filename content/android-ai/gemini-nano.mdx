## 핵심 개념

**Gemini Nano** 는 Google 이 Android 디바이스에 최적화한 온디바이스 파운데이션 모델 (small language model) 이다. Cloud Gemini Pro/Flash 와 달리, 모델 가중치가 디바이스에 직접 배포되어 네트워크 없이 추론이 가능하다. 모델 라이프사이클은 **AICore** 라는 Android 시스템 서비스가 관리하며, 앱은 `com.google.android.gms.ai` 패키지 (Google Play Services AI) 또는 **Google AI Edge SDK** 를 통해 호출한다.

핵심 가치 명제는 세 가지다:
- **Privacy by default** — 입력 데이터가 디바이스를 떠나지 않음
- **Zero network cost** — API 호출 비용 0, 오프라인 동작
- **Low latency** — NPU/하드웨어 가속으로 cloud round-trip 제거

2026 년 현재 Pixel 8 Pro / Pixel 9 / Galaxy S24 시리즈 등 robust RAM + NPU 디바이스에서 Gemini Nano 2 가 안정 동작하며, Gemma 4 기반 Gemini Nano 4 가 Developer Preview 단계에 있다.

## 주요 기능

- **Prompt API** — 텍스트/멀티모달 입력 기반 자유 생성
- **Summarization** — 기사/대화 → 1~3 bullet 요약
- **Proofreading** — 짧은 텍스트 맞춤법·문법 교정
- **Rewriting** — formal / concise / emoji 등 스타일 변환
- **Image Description** — 이미지에 대한 짧은 alt-text 생성
- **Speech Recognition** — 음성 → 텍스트 변환

대부분 ML Kit GenAI APIs 라는 high-level wrapper 로 노출되며, 더 lower-level 제어가 필요할 때 Google AI Edge SDK 를 직접 호출한다.

## 활용 사례

- **메신저 앱**: 답장 제안, 톤 변환, 오프라인 번역 보조
- **노트/메모 앱**: 긴 회의록 요약, 액션 아이템 추출
- **카메라/갤러리**: 사진 캡션 자동 생성 (이미지 → 텍스트)
- **이메일 클라이언트**: 받은 메일 요약 + 답장 draft 생성
- **접근성 도구**: 화면 콘텐츠 음성 설명 (cloud 비의존)

```kotlin
// Google AI Edge SDK 호출 (개념적 예시)
val generativeModel = GenerativeModel(
    generationConfig = generationConfig {
        context = applicationContext
        temperature = 0.2f
        topK = 16
        maxOutputTokens = 256
    }
)

val response = generativeModel.generateContent("회의록 3줄 요약: ...")
Log.d("Nano", response.text ?: "no output")
```

## 한계 및 고려사항

- **디바이스 제한** — 모든 Android 디바이스에서 동작하지 않음. NPU + 충분 RAM 필요 (현재 flagship 위주)
- **컨텍스트 윈도우 작음** — cloud Gemini 대비 입력 길이 제약
- **모델 품질 trade-off** — Nano 는 Pro/Flash 대비 reasoning depth 낮음. 복잡 chain-of-thought 작업은 cloud fallback 권장
- **AICore 의존** — 시스템 서비스가 모델 배포·업데이트 책임. 앱 단독 버전 픽스 불가
- **APK 사이즈와 무관하지만 디스크 소비** — AICore 가 모델을 별도 저장 (수백 MB 단위)
- **권한 모델 진화 중** — 일부 API 는 beta/alpha, Production 사용 전 안정성 검증 필요
