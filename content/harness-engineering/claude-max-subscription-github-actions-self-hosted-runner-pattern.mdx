## 문제

`claude-code-action@v1` 을 GH Actions 에서 사용할 때 두 가지 인증 방법:

1. `claude_code_oauth_token` — Max 구독 OAuth token, **~24h 만료**
2. `anthropic_api_key` — Anthropic API key, **호출당 과금**

Issue-agent, cron 기반 자동화 등 장기 운영 워크플로우에서 OAuth token 은 만료 즉시 401 에러. API key 방식은 Max 구독 외 추가 비용 발생.

```
Error: [claude-code-action] CLAUDE_CODE_OAUTH_TOKEN expired
→ 401 Unauthorized
```

## 해법: Self-Hosted Runner + Claude CLI 직접 호출

`ubuntu-latest` + `claude-code-action@v1` 조합 대신:

```yaml
jobs:
  my-job:
    runs-on: [self-hosted, "home"]  # 로컬 머신
    steps:
      - uses: actions/checkout@v4
      # Node 셋업 등 필요 deps
      - name: Run Claude Code
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          claude --dangerously-skip-permissions -p "
          ... 프롬프트 ...
          "
```

**왜 작동하는가**: Self-hosted runner 는 로컬 머신에서 실행. 로컬에 이미 `claude` CLI 가 Max 구독으로 인증되어 있음. `~/.claude/` 의 토큰이 세션 유지 — 갱신 없이 영구 사용 가능 (login 상태 유지한 경우).

## 인증 지속성 비교

| 방식 | 인증 지속 | 과금 | 인터넷 필요 |
|---|---|---|---|
| `claude-code-action` + OAuth | ~24h → 만료 401 | X (Max 구독) | O |
| `claude-code-action` + API key | 무제한 | O (호출당) | O |
| **Self-hosted + claude CLI** | **Max 구독 세션 유지** | **X** | **O (API 호출 시)** |

## 적합/부적합

**적합:**
- 장기 운영 자동화 (issue-agent, cron workflows, daily check)
- 1인 개발자 + 로컬 머신 항상 온 환경 (self-hosted runner 상시 가동)
- 비용 민감 (ANTHROPIC_API_KEY 추가 과금 회피)
- 워커 레포별 자동화 (blog-autopilot 패턴)

**부적합:**
- 팀 협업 (머신 의존성 — 다른 팀원의 로컬에서 재현 어려움)
- 클라우드 CI (self-hosted runner 없는 순수 GH Actions)
- 로컬 머신 오프라인 시 workflows 미실행

## 운영 고려사항

**Runner 상시 가동**: Self-hosted runner 는 `launchd` (macOS) 또는 `systemd` (Linux) 로 항상 활성 필요.

**Max 구독 세션 갱신**: Claude Code 는 자동 토큰 갱신. 단, `claude login` 세션이 만료되면 (드물지만 가능) workflows 가 실패할 수 있음. 주기적 세션 확인 권장.

**Secret 최소화**: `ANTHROPIC_API_KEY` 를 secrets 에 박제 불필요. `GH_TOKEN`/`GITHUB_TOKEN` 만으로 충분.

## 증거

- **blog-autopilot auto-publish.yml**: `[self-hosted, "home"]` + `npx tsx scripts/auto-publish.ts` — API key 미사용, 상시 성공
- **blog-autopilot issue-agent.yml**: 2026-05-26 fix — `ubuntu-latest + claude-code-action` → `[self-hosted, "home"] + claude CLI`. 401 에러 해소, 6건 이슈 처리 성공 확인
