## 이것이 문제인가?

### 문제 아닌 이유

**JIT 의미 검색이 암묵적 그래프를 형성한다**. `node scripts/search.mjs "<query>"` 는 embeddings 기반 의미 유사성으로 카테고리 경계를 넘어 관련 chunks를 반환. agents/evaluation/context-engineering 간 명시적 연결이 0이어도 검색은 이들을 연결한다.

즉, **connections frontmatter = 편집 큐레이션 마커** (사람이 "이 entry는 저 entry와 함께 읽어라"는 신호), **검색 = 실제 지식 그래프 traversal**.

### 편집 큐레이션 vs 자동 생성 구분

gap-pull/scout 배치로 생성된 entries는 array format으로 10개+ connections 자동 생성. 이 연결들은 편집 의도 없이 의미 유사성만으로 연결됨. 실질 큐레이션 지표는 **YAML list format connections** 수 (수동 작성 evidence):

| 연결 유형 | 형식 | 의미 |
|---|---|---|
| 자동 생성 (gap-pull) | `connections: [a, b, c, ...]` | 의미 유사성 기반, 편집 의도 X |
| 편집 큐레이션 (수동) | `connections:\n  - a\n  - b` | 명시적 "함께 읽어라" 신호 |

편집 큐레이션 비율이 실질 wiki 지식 그래프 품질 지표. cross-category 51.8%는 자동 생성 포함 수치 — 편집 큐레이션만 측정 시 더 낮을 가능성 있음.

## Orphan Link 패턴

deletion 시 역방향 연결 미정리 = orphan link 생성. 수동 체크:

```bash
python3 -c "
import os, re, glob

mdx_files = glob.glob('content/**/*.mdx', recursive=True)
all_slugs = set(os.path.basename(f).replace('.mdx','') for f in mdx_files)

for f in mdx_files:
    content = open(f).read()
    m = re.search(r'connections:\s*\n((?:\s*-\s*.+\n)*)', content)
    if m:
        for c in re.findall(r'-\s*(.+)', m.group(1)):
            slug = c.strip().split('/')[-1]
            if slug and slug not in all_slugs:
                print(f'ORPHAN: {os.path.basename(f)} -> {slug}')
"
```

## curate 시 권장 행동

1. **새 entry 생성 시**: connections 최소 1개 의무 (CLAUDE.md 규칙)
2. **curate chain 실행 시**: 편집 큐레이션 connections (YAML list format) 1~2건 추가
3. **orphan link 스캔**: 아래 정확한 파싱 스크립트 사용 (양쪽 format 모두 체크)
4. **측정 스크립트 주의**: connections array format (`[a, b]`) vs YAML list format (`\n  - a`) 모두 처리 필요

```python
# 정확한 orphan 스캔
import re, glob, os
mdx_files = glob.glob('content/**/*.mdx', recursive=True)
all_slugs = set(os.path.basename(f).replace('.mdx','') for f in mdx_files)
for f in mdx_files:
    content = open(f).read()
    # YAML list
    m = re.search(r'connections:\s*\n((?:[ \t]+-[ \t]+.+\n?)*)', content)
    if m:
        for c in re.findall(r'-\s*(.+)', m.group(1)):
            slug = c.strip().split('/')[-1]
            if slug and len(slug) > 3 and slug not in all_slugs:
                print(f'ORPHAN: {os.path.basename(f)} -> {c.strip()}')
    # Array
    m2 = re.search(r'connections:\s*\[([^\]]+)\]', content)
    if m2:
        for c in m2.group(1).split(','):
            slug = c.strip().split('/')[-1]
            if slug and slug not in all_slugs:
                print(f'ORPHAN: {os.path.basename(f)} -> {c.strip()}')
```
