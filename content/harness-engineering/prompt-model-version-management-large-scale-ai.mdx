대규모 AI 시스템, 특히 Large Language Models (LLMs) 기반 애플리케이션의 복잡성은 2026년 현재에도 끊임없이 진화하고 있습니다. 프롬프트 (Prompt), 모델 (Model), 그리고 학습 데이터셋 (Dataset)의 빈번한 변경은 예측 불가능한 동작, 성능 저하, 그리고 심각한 재현성 (Reproducibility) 문제를 야기할 수 있습니다. 이러한 문제를 해결하고 안정적이며 감사 가능한 (Auditable) AI 시스템을 구축하기 위해서는 체계적인 프롬프트 및 모델 버전 관리가 필수적입니다. 이는 모델 드리프트 (Model Drift) 및 프롬프트 드리프트 (Prompt Drift)를 효과적으로 감지하고 완화하는 데 핵심적인 역할을 합니다. 복잡한 AI 에이전트 시스템이나 다중 모델 환경에서는 더욱 그 중요성이 부각됩니다.

## 프롬프트 버전 관리 (Prompt Version Management)

프롬프트는 AI 모델의 행동을 직접적으로 제어하는 핵심적인 구성 요소입니다. 대규모 시스템에서 프롬프트의 변경은 코드 변경만큼이나 신중하게 다루어져야 합니다.

### Git 기반 접근 방식

프롬프트는 일반적인 텍스트 파일이나 JSON, YAML과 같은 설정 파일 형태로 관리될 수 있습니다. 이를 Git 저장소에 코드와 함께 버전 관리하는 것이 가장 기본적인 전략입니다. 이 방식은 다음과 같은 이점을 제공합니다:

*   **변경 이력 추적**: 모든 프롬프트 변경 사항이 커밋 (commit) 단위로 기록되어, 언제 누가 무엇을 변경했는지 쉽게 파악할 수 있습니다.
*   **롤백 (Rollback)**: 문제가 발생했을 때 이전 버전의 프롬프트로 신속하게 되돌릴 수 있습니다.
*   **협업 (Collaboration)**: Pull Request (PR) 기반의 코드 리뷰 프로세스를 통해 프롬프트 변경에 대한 동료 검토 및 승인을 받을 수 있어, 의도치 않은 변경을 방지하고 품질을 향상시킬 수 있습니다.
*   **브랜치 전략 (Branching Strategy)**: 특정 실험이나 기능 개발을 위한 브랜치를 생성하여 주 개발 라인에 영향을 주지 않고 프롬프트 테스트 및 개선 작업을 수행할 수 있습니다.

### 전용 프롬프트 레지스트리 (Prompt Registry)

단순한 Git 관리만으로는 부족한 경우, 전용 프롬프트 관리 시스템 또는 레지스트리 (Prompt Registry)를 구축하거나 활용할 수 있습니다. 이는 프롬프트의 ID, 버전, 메타데이터 (작성자, 목적, 관련 모델 버전 등), 그리고 테스트 결과를 중앙에서 관리합니다. Semantic versioning (예: `v1.0.0`, `v1.0.1`, `v2.0.0`)을 적용하여 프롬프트의 호환성 변화를 명확히 하고, 배포 및 롤백을 용이하게 합니다.

### 플레이스홀더 및 템플릿 (Placeholders and Templating)

Jinja2, Handlebars와 같은 템플릿 엔진을 사용하여 프롬프트의 동적 부분을 관리할 수 있습니다. 이는 프롬프트의 핵심 구조를 유지하면서, 특정 사용자, 세션, 또는 배포 환경에 맞는 변수 (예: `{user_name}`, `{context_data}`)를 주입하는 것을 가능하게 합니다. 베이스 프롬프트의 버전을 유지하면서 변수 주입 로직을 분리함으로써, 프롬프트 관리의 유연성을 높입니다.

## 모델 버전 관리 (Model Version Management)

학습된 AI 모델 자체도 프롬프트만큼 중요한 버전 관리 대상입니다. 모델 버전 관리는 MLOps 파이프라인의 핵심 요소입니다.

### 모델 레지스트리 (Model Registry)

MLflow, SageMaker Model Registry, Hugging Face Hub, Kubeflow 등과 같은 도구들은 학습된 모델의 바이너리, 메타데이터 (성능 지표, 하이퍼파라미터, 학습 데이터셋 lineage), 그리고 관련 아티팩트 (Artifact)를 등록하고 관리하는 기능을 제공합니다. 각 모델 버전은 고유한 식별자 (예: `model_name/version_id`)를 가지며, 스테이징 (Staging), 프로덕션 (Production), 아카이브 (Archive) 등 라이프사이클 단계를 추적합니다. 이는 모델의 배포 승인 (Approval), 모니터링 (Monitoring), 그리고 롤백 프로세스를 간소화합니다.

### 불변 아티팩트 (Immutable Artifacts)

한번 배포된 모델 버전은 변경되지 않는 불변 아티팩트로 취급해야 합니다. 새로운 변경이 필요할 경우, 항상 새 버전을 생성하고 배포해야 합니다. 이는 재현성을 보장하고, 프로덕션 환경에서 예기치 않은 부작용을 방지하는 데 필수적입니다. 데이터 버전 관리 (DVC: Data Version Control)와 같은 도구를 활용하여 모델 학습에 사용된 데이터셋의 버전을 모델 버전과 연결함으로써, 학습 환경의 재현성을 완벽하게 보장할 수 있습니다.

## 통합 및 오케스트레이션 (Integration and Orchestration)

프롬프트와 모델 버전 관리는 개별적인 활동이 아니라, CI/CD (Continuous Integration/Continuous Deployment) 파이프라인에 통합되어야 합니다. 이는 개발부터 배포, 그리고 운영에 이르는 전 과정에서 안정성과 효율성을 극대화합니다.

새로운 프롬프트 또는 모델 버전이 커밋되거나 등록되면, 자동화된 테스트, 평가, 그리고 배포 프로세스가 트리거됩니다. API Gateway 또는 SDK를 통해 특정 버전의 프롬프트 및 모델을 호출할 수 있도록 하여, A/B 테스트, 카나리 배포 (Canary Deployments), 그리고 Blue/Green 배포와 같은 고급 배포 전략을 지원합니다. 이를 통해 새로운 프롬프트나 모델 버전이 프로덕션 환경에 미치는 영향을 최소화하면서 점진적으로 적용할 수 있습니다.

```python
# prompt_model_manager.py
import json
import os
from datetime import datetime
import shutil # For demonstration of prompt directory management

class PromptManager:
    """프롬프트 버전 관리를 위한 간단한 레지스트리"""
    def __init__(self, registry_base_path="prompt_registry"):
        self.registry_base_path = registry_base_path
        os.makedirs(registry_base_path, exist_ok=True)

    def save_prompt(self, name: str, version: str, content: str, metadata: dict = None):
        prompt_dir = os.path.join(self.registry_base_path, name)
        os.makedirs(prompt_dir, exist_ok=True)
        
        prompt_file_path = os.path.join(prompt_dir, f"{version}.json")
        data = {
            "name": name,
            "version": version,
            "content": content,
            "metadata": metadata if metadata else {},
            "created_at": datetime.now().isoformat()
        }
        with open(prompt_file_path, "w", encoding="utf-8") as f:
            json.dump(data, f, indent=2, ensure_ascii=False)
        print(f"Prompt '{name}' version '{version}' saved to {prompt_file_path}")
        return prompt_file_path

    def load_prompt(self, name: str, version: str = "latest") -> dict:
        prompt_dir = os.path.join(self.registry_base_path, name)
        if not os.path.exists(prompt_dir):
            raise FileNotFoundError(f"Prompt '{name}' not found in registry.")

        target_version = version
        if version == "latest":
            versions = sorted([f.split('.')[0] for f in os.listdir(prompt_dir) if f.endswith('.json')], reverse=True)
            if not versions:
                raise FileNotFoundError(f"No versions found for prompt '{name}'.")
            target_version = versions[0]
        
        prompt_file_path = os.path.join(prompt_dir, f"{target_version}.json")
        if not os.path.exists(prompt_file_path):
            raise FileNotFoundError(f"Prompt '{name}' version '{target_version}' not found.")
        
        with open(prompt_file_path, "r", encoding="utf-8") as f:
            return json.load(f)

    def delete_prompt_registry(self):
        """Demonstration: Clean up the prompt registry directory"""
        if os.path.exists(self.registry_base_path):
            shutil.rmtree(self.registry_base_path)
            print(f"Deleted prompt registry at {self.registry_base_path}")

class ModelRegistry:
    """모델 버전 관리를 위한 간단한 레지스트리 (실제 MLflow 등 대체)"""
    def __init__(self):
        self.models = {}

    def register_model(self, name: str, version: str, artifact_path: str, metadata: dict = None):
        if name not in self.models:
            self.models[name] = {}
        self.models[name][version] = {
            "artifact_path": artifact_path,
            "metadata": metadata if metadata else {},
            "registered_at": datetime.now().isoformat()
        }
        print(f"Model '{name}' version '{version}' registered with path '{artifact_path}'.")

    def get_model_artifact_path(self, name: str, version: str = "latest") -> str:
        if name not in self.models:
            raise ValueError(f"Model '{name}' not found in registry.")
        
        target_version = version
        if version == "latest":
            versions = sorted(self.models[name].keys(), reverse=True)
            if not versions:
                raise ValueError(f"No versions found for model '{name}'.")
            target_version = versions[0]

        if target_version not in self.models[name]:
            raise ValueError(f"Model '{name}' version '{target_version}' not found.")
        
        return self.models[name][target_version]["artifact_path"]

# Usage Example
if __name__ == "__main__":
    prompt_manager = PromptManager()
    model_registry = ModelRegistry()

    # 프롬프트 버전 저장
    prompt_manager.save_prompt(
        "summarization_basic", "1.0.0", 
        "Summarize the following text briefly: {text}", 
        {"author": "AI Team A", "purpose": "general summary"}
    )
    prompt_manager.save_prompt(
        "summarization_basic", "1.0.1", 
        "Provide a concise summary of the key points from the following text: {text}", 
        {"author": "AI Team B", "purpose": "improved clarity"}
    )
    prompt_manager.save_prompt(
        "summarization_advanced", "2.0.0", 
        "Analyze the sentiment and summarize the main arguments of the given document: {document}", 
        {"author": "AI Team C", "purpose": "sentiment + summary", "requires_sentiment_model": True}
    )
    
    # 프롬프트 로드
    loaded_prompt_v1_0_0 = prompt_manager.load_prompt("summarization_basic", "1.0.0")
    print(f"\nLoaded Prompt 1.0.0: {loaded_prompt_v1_0_0['content']}")
    
    loaded_latest_prompt = prompt_manager.load_prompt("summarization_basic", "latest")
    print(f"Loaded Latest Prompt (summarization_basic): {loaded_latest_prompt['content']}")

    # 모델 버전 등록 (실제로는 모델 학습 후 MLflow 등에 등록)
    model_registry.register_model(
        "text_encoder", "2026.01.15", "/models/text_encoder/2026.01.15_bert.pth", 
        {"accuracy": 0.92, "dataset_version": "v1.0"}
    )
    model_registry.register_model(
        "text_encoder", "2026.03.20", "/models/text_encoder/2026.03.20_roberta.pth", 
        {"accuracy": 0.935, "dataset_version": "v1.1", "model_arch": "RoBERTa"}
    )
    model_registry.register_model(
        "sentiment_classifier", "2026.02.01", "/models/sentiment_clf/2026.02.01_svc.pkl",
        {"f1_score": 0.88, "training_data_size": "1M"}
    )

    # 모델 아티팩트 경로 가져오기
    model_path_v1 = model_registry.get_model_artifact_path("text_encoder", "2026.01.15")
    print(f"\nModel Artifact Path v1 (text_encoder): {model_path_v1}")
    
    latest_model_path = model_registry.get_model_artifact_path("text_encoder", "latest")
    print(f"Latest Model Artifact Path (text_encoder): {latest_model_path}")

    sentiment_model_path = model_registry.get_model_artifact_path("sentiment_classifier")
    print(f"Latest Sentiment Model Artifact Path: {sentiment_model_path}")

    # Clean up (for demonstration)
    prompt_manager.delete_prompt_registry()
```
