AI 에이전트가 복잡한 코드베이스를 이해하고 추론하는 과정에서 발생하는 높은 토큰 비용은 지속적인 문제였습니다. 특히 코드의 동작 방식이나 구성에 대한 구조적 질문에 답변할 때, 기존 방식은 여러 파일을 탐색하고 `grep`, `import` 추적 등을 반복하며 비효율적으로 많은 토큰을 소모합니다. 이러한 비효율성을 극복하기 위한 핵심 전략 중 하나가 바로 코드 그래프(Code Graph)의 통합입니다. 코드 그래프는 코드베이스의 구조와 관계를 미리 파싱하고 구조화된 형태로 제공하여, 에이전트가 필요한 정보를 정확하고 경제적으로 접근하도록 돕습니다.

## 코드 그래프의 기본 원리 및 Claude Code 하네스 통합

코드 그래프는 TypeScript 컴파일러와 같은 도구가 소스 코드를 구문 분석(parsing)하고, 추상 구문 트리(Abstract Syntax Tree, AST)를 생성하며, 이후 코드 내의 다양한 요소(함수, 변수, 클래스, 모듈 등) 간의 호출 관계, 의존성, 상속 관계 등을 분석하여 그래프 형태로 표현한 것입니다. `@ttsc/graph`와 같은 도구는 이러한 TypeScript 컴파일러의 내부 분석 결과를 활용하여, 코드의 정적 구조에 대한 풍부한 메타데이터를 추출합니다. 이 메타데이터는 단순한 텍스트 파일 내용을 넘어서는 깊이 있는 컨텍스트를 제공합니다.

Claude Code 하네스에 코드 그래프를 통합하는 핵심 아이디어는 다음과 같습니다.

1.  **구조화된 컨텍스트 제공**: 에이전트가 코드 구조에 대한 질문을 할 때, 파일 시스템을 직접 탐색하는 대신 미리 생성된 코드 그래프를 쿼리합니다.
2.  **토큰 절감**: 코드 그래프는 필요한 정보만 압축된 형태로 제공하므로, 전체 파일을 LLM의 컨텍스트 윈도우에 로드할 필요가 없어 토큰 사용량을 획기적으로 줄일 수 있습니다 (최대 10배 절감 효과). 이는 특히 대규모 코드베이스에서 더욱 큰 이점을 가집니다.
3.  **정확성 및 효율성**: 에이전트는 코드 그래프를 통해 함수 호출 스택, 모듈 의존성, 특정 심볼의 정의 및 사용처 등을 즉시 파악할 수 있어, 추론의 정확성과 속도가 향상됩니다.

### 코드 그래프 생성 및 활용 예시

다음은 TypeScript 코드에서 코드 그래프를 생성하고 활용하는 기본적인 흐름을 보여줍니다. 실제 `@ttsc/graph`와 같은 라이브러리는 더 복잡한 추상화를 제공하지만, 여기서는 개념적인 이해를 돕기 위한 예시입니다.

**src/utils.ts**
```typescript
export function add(a: number, b: number): number {
  return a + b;
}

export function multiply(a: number, b: number): number {
  return a * b;
}
```

**src/index.ts**
```typescript
import { add, multiply } from './utils';

function calculate(x: number, y: number): number {
  const sum = add(x, y);
  const product = multiply(x, y);
  return sum + product;
}

console.log(calculate(5, 3));
```
