## 무한성장 산식 갱신

기존: 정적 % baseline (4-24 vibes "30%")
신규: **정적 + velocity + acceleration** (시간축 vector)

```
정적 (현재 시점)        ← 8+7 차원 baseline
미분 (velocity, 1주)    ← 추세 (가속/감속/정체)
2차 미분 (acceleration) ← 추세의 변화 (다음 주 가속할까)
```

진짜 무한성장 = velocity > 0 + acceleration ≥ 0 *지속*. 평균 % 폐기.
