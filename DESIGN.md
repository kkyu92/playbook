# Playbook Hub — Design System

## Theme: Neon Terminal
Warp/Cyberpunk 계열. 초고채도 네온 컬러 on 다크 배경. 강렬하고 미래적. 해커 터미널 느낌.

## Typography
- Display: Geist Sans, system-ui, sans-serif (weight: 800)
- Body: Geist Sans, Pretendard Variable, sans-serif
- Code: Geist Mono, JetBrains Mono, monospace

## Spacing
- xs: 4px, sm: 8px, md: 16px, lg: 24px, xl: 32px

## Border Radius
- sm: 6px, md: 8px, lg: 12px

## Effects
- Card hover: box-shadow with category color at 15% opacity
- Magnetic mode: Cursor glow cyan #06b6d4
- Neon glow: text-shadow with category color for headings (optional)
