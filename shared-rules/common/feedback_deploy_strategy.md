커밋은 자유롭게 마음껏. **사용자가 명시한 커밋 분할 방식은 그대로 따르고, 커밋 개수 제한이나 묶음 방식을 다시 묻지 말 것** (2026-04-19 사용자 명시: "커밋은 제한이 없어 다음부터 묻지마"). push는 사용자가 "푸시해/배포해" 라고 할 때만, 또는 작업 단위 끝에 한 번에.
**Why:** Vercel 일 100회 배포 제한. push 마다 자동 배포 트리거되므로 낭비 방지. 한편 로컬 커밋은 비용이 0 이라 쪼개도 무방하고 history를 명확하게 남기는 게 더 가치 있음.
**How to apply:** 사용자가 "조합별 N개 커밋" 같이 분할 방식을 지정하면 그대로 실행, 추가 확인 금지. push 시점만 사용자 신호 (push/배포/땡겨/올려 등) 기다림.
